IoT Air Monitoring

Website ini menampilkan data kualitas udara yang dikirim oleh perangkat IoT. Data diperbarui otomatis setiap 5 detik.

Cara Kerja

1

Perangkat IoT membaca suhu, tekanan, dan lokasi.

2

Perangkat mengirim data ke server Go.

3

Server Go menyimpan data ke database MySQL.

4

Dashboard menampilkan data terbaru dan grafiknya.

Data yang Dipantau

  • Suhu dalam derajat Celsius (°C)
  • Tekanan udara dalam hektopascal (hPa)
  • Lokasi perangkat (latitude dan longitude)
  • Kualitas udara: Bersih atau Kurang Baik
